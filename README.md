# Marketing Grupo Vivencia — El Dorado

Contenido para redes (Facebook, TikTok, YouTube) del proyecto El Dorado, Puerto Maldonado.

- `datos/` — datos aprobados por Luis, borradores e historial de lo publicado.
- `remotion/` — proyecto que arma los videos y carruseles.
- `salidas/semana-NN/` — piezas de cada semana (las arma el agente automático cada miércoles).
- `AGENTE.md` — instrucciones del agente automático.

Cada semana el agente deja las publicaciones en Metricool **como borrador**. Nada sale sin la aprobación de Luis.
